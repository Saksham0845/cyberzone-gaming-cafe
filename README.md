# 🕹️ CyberZone - Next-Gen Gaming Arena & Esports Hub

A high-end, cyberpunk-themed landing page and slot-booking web application built for modern gaming cafes. Designed with a sleek neon aesthetic, responsive grid layouts, and interactive booking modals.

## ✨ Features
- **Cyberpunk Aesthetic:** Deep dark backgrounds (`#080b12`) accented with glowing cyan (`#00f3ff`) and magenta (`#ff0055`) neon effects.
- **Interactive Booking Modal:** Dynamic pop-up system that targets specific gaming zones (VIP PC Arena, Streamer Suite, PS5 Lounge) and manages form submissions without page reloads.
- **Responsive Design:** Fully adaptive layout utilizing CSS Grid and Flexbox for seamless viewing across screens.
- **Zone Breakdowns:** Clear pricing cards featuring high-end hardware specifications (RTX 4090 rigs, 240Hz OLED displays, Shure SM7B mics, PS VR2).

## 🛠️ Tech Stack
- **HTML5:** Semantic markup and structure.
- **CSS3:** Flexbox, CSS Grid, custom keyframe animations, and glowing box shadows.
- **JavaScript (ES6):** DOM manipulation, event handling, and modal state control.
